# QuantFX

> Important: QuantFX is currently a work in progress.

**QuantFX** is a multipurpose and open-source quantitative trading platform for a plethora of different asset types depending on what provider you choose. 

### Featureset
- Real-time data integration from a provider of your choice
- Robust strategy framework, many default algorithms included
- Bayesian optimization engine, Kelly Criterion-powered position sizing and other advanced features
- Powerful CPP-based execution engine for ultra-low latency trading, HFT support
- Strong risk management techniques incorporated, trailing stop loss...
