# Code Projects

Below you can find a list of all programming projects, applications and tools I've built, with links to documentation.

### The List

[**Quantlab**](quantlab/README.md), an open-source backtesting engine built using Python and controllable via a web interface.\
[**Tradelab**](tradelab/README.md), a tool to determine the mathematical viability of a strategy using the Universal Growth Rate Model, as well as outputting other metrics like optimal position sizing.\
[**Livenode**](livenode/README.md) is a minimalist trading bot with a C++/Python hybrid architecture, designed for Alpaca API — currently operating as a paper trader.\
[**Dailymarket**](dailymarket/README.md) is a command-line application that indexes trending stocks based on current price changes, and returns them in a clean format.
