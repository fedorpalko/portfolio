# Livenode

Livenode is a minimal trading bot built using Python as the signal and strategy engine and C++ for trade execution. It's built upon the Alpaca API and now designed specifically for paper trading without any real capital.

> **Important Disclaimer:** Livenode is purely a demonstration project and should probably not be used for live trading, unless you know what you are doing and are capable of modifying it to meet your specific needs.
